### **1️⃣ GET `/points.geojson`**
**Descrizione:**  
- Recupera i punti di interesse (POI) in formato **GeoJSON**, utile per rappresentare dati geospaziali.

**Funzionamento:**  
- Esegue una richiesta per ottenere i dati geospaziali.  
- La risposta dovrebbe essere un file **GeoJSON** contenente i punti sulla mappa.
