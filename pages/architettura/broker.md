# Broker

## Overview

Le Broker API sono interfacce applicative progettate per fungere da intermediari (o "broker") tra diversi sistemi
, applicazioni o servizi.  
Il loro scopo principale è semplificare la comunicazione e l'integrazione tra sistemi
, spesso fornendo un livello di astrazione e gestione centralizzata.

## Tecnologia
Le REST Api del Broker sono sviluppate in python sfruttando Django , framework open-source basato su Python 
per lo sviluppo rapido di applicazioni web. È progettato per aiutare gli sviluppatori a creare applicazioni robuste, scalabili e sicure in modo semplice e veloce.
