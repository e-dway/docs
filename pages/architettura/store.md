# Store

## Overview

L'infrastruttura ha a disposizione un object storage basato sull'opensource Minio

## Tecnologia

**MinIO** è una soluzione open-source di **object storage** ad alte prestazioni, compatibile con l'API **Amazon S3**. È progettato per gestire file e dati non strutturati, come immagini, video, log e backup, offrendo un'alternativa scalabile, sicura ed economica rispetto ad altre piattaforme cloud.

---

### **Caratteristiche Principali di MinIO**

1. **Compatibilità con API S3**:
   - MinIO implementa l'API Amazon S3, consentendo di utilizzare gli stessi strumenti e librerie S3 per interagire con MinIO.

2. **Archiviazione Oggetti (Object Storage)**:
   - I file sono archiviati come oggetti con metadati associati, ideali per dati non strutturati.

3. **Alta Prestazione**:
   - MinIO è ottimizzato per la gestione di grandi volumi di dati e supporta throughput elevati per applicazioni intensive.

4. **Scalabilità**:
   - Può scalare da un singolo nodo a cluster distribuiti, gestendo exabyte di dati.

5. **Sicurezza Avanzata**:
   - Include crittografia end-to-end, supporto TLS/SSL, e autenticazione basata su chiavi (access key e secret key).

6. **Interfaccia Semplice**:
   - Offre un'interfaccia web intuitiva per caricare, gestire e scaricare file.

7. **Disponibilità On-Premises e in Cloud**:
   - Può essere utilizzato localmente, in cloud privati o come parte di infrastrutture ibride.
