# Core

## Overview

Api che gestisce le info conservate nella base dati principale (vedi sezione descrizione database sotto la sezione dedicata) è il nodo centrale da cui attingono tutte gli altri servizi , alcune informazioni esposte sono messe in una cache sfruttando il servizio redis.

## Tecnologia

Redis (Remote Dictionary Server) è un archivio dati open-source in-memory utilizzato come database, cache, message broker e motore di streaming. È noto per le sue prestazioni elevate, supportando molteplici strutture dati e fornendo funzionalità avanzate per l'elaborazione e la gestione dei dati.
