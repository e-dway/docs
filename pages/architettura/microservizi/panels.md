# Panel

## Overview

Servizio per poter gestione dei pannelli informativi (in formato html) che gli operatori possono costruire dall'applicativo di backoffice e verranno visualizzati dagli utenti all'interno dell'app mobile , attraverso l'utilizzo di Grapesjs.

## Tecnologia

Se stai cercando un componente JavaScript evoluto per costruire pagine HTML dinamicamente senza scrivere codice, e che possa essere integrato in un progetto Angular (**ng**), una delle soluzioni più popolari e avanzate è **GrapeJS**.

---

### **GrapeJS**
**GrapeJS** è un framework JavaScript open-source per la creazione e l'editing di contenuti HTML dinamici tramite un'interfaccia drag-and-drop. È progettato per sviluppatori e utenti non tecnici, consentendo di costruire pagine web e modelli email senza scrivere codice.

---

### **Caratteristiche Principali**

1. **Editor Visuale Drag-and-Drop**:
   - Consente agli utenti di trascinare e rilasciare componenti (es. bottoni, testi, immagini) per creare strutture HTML.

2. **Generazione di Codice HTML/CSS**:
   - Fornisce un'anteprima e il codice HTML/CSS generato per integrare il design nelle applicazioni.

3. **Completamente Personalizzabile**:
   - Può essere esteso con plugin e configurato per adattarsi alle esigenze specifiche del progetto.

4. **Supporto Modelli**:
   - Permette di creare modelli personalizzati che gli utenti possono riutilizzare.

5. **Integrabile in Frameworks come Angular**:
   - Può essere integrato facilmente in un'app Angular come componente di terze parti.

6. **API Flessibili**:
   - Dispone di API per personalizzare il comportamento dell'editor, i componenti disponibili e la configurazione.
